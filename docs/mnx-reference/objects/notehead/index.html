The notehead object

Type: Dictionary

Describes the shape and glyph of a notehead. This is purely for visual purposes and doesn't in itself affect pitch, duration or performance.

Generally it's better to encode "shape" instead of "glyph", because the former is a more general concept. For example, the notehead shape "oval" is typically represented as the SMuFL glyph "noteheadHalf" for half notes, "noteheadBlack" for smaller rhythmic values, etc. Encoding "shape" instead of a hard-coded "glyph" makes the document more flexible.

In tuplets and multi-note tremolos, use the displayed note value rather than the elapsed performance duration.

For a kit note, an omitted shape or "default" uses the kit component's notehead, including its glyph. An explicit shape such as "oval" replaces the component's shape and glyph. An explicit glyph on the kit note overrides the selected notehead's appearance.

MNX doesn't currently have a way to assign notehead shapes dynamically according to pitch or staff position, such as shape-note notation. Applications may still encode such settings using vendor extensions. When no kit-component notehead applies and a notehead's shape is omitted or set to "default", consuming software may use those settings to choose its shape. An explicit shape, such as "oval" or "diamond", should override that setting.

Attributes

Name Type Required? Description
glyph smufl glyph No An explicit SMuFL glyph for this notehead. An explicit shape is required when a glyph is supplied. Use a known shape to retain its semantics while refining its appearance, or ("custom") for an otherwise unclassified head.

The glyph overrides duration-dependent glyph selection. It does not change pitch, duration or performance.
shape notehead shape No The semantic shape family of this notehead. Shape selection does not change pitch, duration, or performance. For example, "diamond" does not by itself specify an artificial harmonic, and "slash" does not specify pitchless notation or a beat repeat. For a kit note, "default" uses its kit component's head design; an explicit shape such as "oval" replaces that design.

If omitted, the value is "default".

Plus globally available attributes: _c, _x, id
