The chord suffix stack object

Type: Dictionary

Two or more rows of a chord suffix arranged on top of one another, such as a stacked "6/9" or a column of alterations.

Consuming software determines the size of the rows, the spacing between them, and how the stack is aligned with the baseline of the surrounding suffix. Normally the rows are drawn smaller than the baseline text and the stack is centered on the suffix's text.

An enclosure is sized to the height of the whole stack. For example, a stack of two rows enclosed in parentheses might be drawn with the SMuFL glyphs csymParensLeftTall and csymParensRightTall, and a stack of three rows with csymParensLeftVeryTall and csymParensRightVeryTall.

Stacks cannot contain other stacks.

Attributes

Name Type Required? Description
type The string "stack" Yes This disambiguates stacks from text runs and SMuFL runs.
rows An array of chord suffix row objects Yes The rows of the stack, in order from top to bottom.
arrangement chord suffix stack arrangement No How the rows are arranged.

If omitted, the default value is "vertical".
enclosure chord suffix enclosure No The enclosure drawn around the whole stack.

If omitted, the default value is "none".
level chord suffix level No The vertical level of the stack as a whole.

If omitted, the default value is "baseline".

Plus globally available attributes: _c, _x, id
