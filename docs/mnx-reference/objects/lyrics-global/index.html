The lyrics-global object

Type: Dictionary

Document-wide lyric data. This is required if any event in the document has lyrics.

Attributes

Name Type Required? Description
lineMetadata An object with user-defined keys, where each value is a lyric line metadata No An object mapping lyric line IDs to lyric metadata objects. This encodes global metadata on a per-lyric-line basis. Each key must be an ID listed in lineOrder.
lineOrder An array of lyric line ID objects Yes An array of all lyric line IDs used in this MNX document (i.e., keys used by "lineMetadata" and lyrics.lines), in the order in which they should be visually displayed (from top to bottom).

Each ID must appear exactly once in this array.

Plus globally available attributes: _c, _x, id
