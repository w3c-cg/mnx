The smufl glyph object

Type: String

A string representing a glyph name in the SMuFL music-font-encoding specification. In MNX, this is generally used to override default engraving behavior. Example SMuFL glyph name: noteheadXOrnateEllipse

Parent objects

This object is used by the following parent objects:

  • accent dynamic: "glyphs"
  • clef: "glyph"
  • gradual dynamic: "glyphs"
  • immediate dynamic: "glyphs"
  • relative dynamic: "glyphs"
  • segno: "glyph"
