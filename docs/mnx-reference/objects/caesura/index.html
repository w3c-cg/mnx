The caesura object

Type: Dictionary

Defines a caesura. Note that MNX allows caesuras to be encoded in two distinct places:

  1. An event. In this case, the caesura should be encoded on the event before the caesura happens — generally the event that contains note(s) that are performed directly before the caesura.
  2. A measure global. This is used for caesuras that are centered above barlines — i.e., not semantically associated with a specific event.

Attributes

Name Type Required? Description
marks positive integer No The number of marks/strokes to use in this caesura. Must be either 1 or 2.

If unspecified, the default value is 2.
shape caesura shape No The visual shape of the caesura.

If unspecified, the default value is "normal".

Plus globally available attributes: _c, _x, id

Parent objects

This object is used by the following parent objects:

  • event markings: "caesura"
  • measure global: "caesura"
