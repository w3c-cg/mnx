The positioned staff config object

Type: Dictionary

Represents a staff config as positioned at a specific location within a measure.

Attributes

Name Type Required? Description
config staff config Yes
position rhythmic position No If this position isn't provided, it's assumed to be the start of the bar.
staff staff number No In a multi-staff part, this specifies which staff the config applies to. If unspecified, this should be interpreted as 1.

Plus globally available attributes: _c, _x, id
