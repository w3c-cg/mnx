The positioned text object

Type: Dictionary

Represents text as positioned at a specific location within a measure.

If the position isn't encoded, the position is assumed to be the start of the measure.

Attributes

Name Type Required? Description
text An array of text chunk (text) objects, text chunk (SMuFL) objects Yes The text itself. This is encoded as a heterogeneous array of chunks, which can contain a mixture of "text chunks" and "SMuFL chunks."
type text type No The type of text. If unspecified, this should be interpreted as "general".
position rhythmic position No If this position isn't provided, the text's position is assumed to be the start of the bar.
staff staff number No In a multi-staff part, this specifies which staff the text is in. If unspecified, this should be interpreted as 1.
placement placement No Whether this text is displayed above or below the staff.

If omitted, the default value is "auto".

Plus globally available attributes: _c, _x, id
