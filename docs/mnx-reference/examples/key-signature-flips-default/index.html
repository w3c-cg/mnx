Key signature flips (default behavior)

If a part's transposition doesn't specify "keyFifthsFlipAt", the key signature never flips enharmonically, no matter how many sharps or flats result.

Both E♭ parts here transpose up a major sixth, so the concert key signatures of 4 and 6 sharps become written key signatures of 7 and 9 sharps. The first part uses "keyFifthsFlipAt": 7, so these become 5 flats and 3 flats. The second part omits "keyFifthsFlipAt", so the second measure has 9 sharps, including two double sharps.
