The chord suffix level object

Type: String

The semantic vertical level of part of a chord suffix. Consuming software determines the actual offset and size for each level.

Allowed values:

Value Description
"baseline" On the baseline of the chord symbol, at the normal size of the suffix.
"subscript" Lowered below the baseline and normally reduced in size.
"superscript" Raised above the baseline and normally reduced in size, as is common for extensions in jazz styles (for example, the 7 in "MA⁷").

Parent objects

This object is used by the following parent objects:

  • chord suffix SMuFL run: "level"
  • chord suffix stack: "level"
  • chord suffix text run: "level"
