The label ref object

Type: Dictionary

The label ref object displays a part's name or shortName as the label for a staff, staff source or staff group, so the name doesn't need to be duplicated in the layout.

As with the "label" attribute of staff, staff group and staff source, any label ref that is provided should be displayed, and consuming software is responsible for deciding how best to position it.

Attributes

Name Type Required? Description
ref label ref type No Which name to display. If omitted, the default value is "auto".
target ID No The ID of the part whose name is displayed.

If this is omitted on a staff source, consuming software should use the source's own part. If omitted on a staff, software should use the part of the staff's first source. If omitted on a staff group, software should determine the target according to its own algorithm.

We recommend always supplying the target for staff group objects.

Plus globally available attributes: _c, _x, id

Parent objects

This object is used by the following parent objects:

  • staff: "labelRef"
  • staff group: "labelRef"
  • staff source: "labelRef"

Examples

This object is used in the following examples:

Bracket (square), Multiple layouts, System layouts
