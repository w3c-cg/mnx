The staff symbol object

Type: String

Allowed values:

Value Description
"brace"
"bracket"
"noSymbol"
"square" A thin square bracket with short horizontal ends, commonly used to group staves for different players of the same instrument.

Parent objects

This object is used by the following parent objects:

  • staff: "symbol"
  • staff group: "symbol"

Examples

This object is used in the following examples:

Bracket (square), Multiple layouts, Orchestral layout, Organ layout, System layouts
