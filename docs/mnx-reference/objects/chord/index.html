The chord object

Type: Dictionary

Represents a chord symbol (e.g., "Am" or "G7").

Attributes

Name Type Required? Description
simpleName string No A text-only name of this chord. Examples: "Am", "Cmaj7", "C#", "C♯", "G/A", "Bb-".

This provides a lowest-common-denominator way for applications to encode chord names without needing to deal with parsing "root". or "kind".

Unicode characters are allowed (i.e., this isn't limited to ASCII), and there is no particular constraint on the data.
root note step with alter No The chord's root.
kind chord-kind No The kind of chord, such as major, minor, dominant, etc.
bass note step with alter No The chord's bass note. For example, in a "G/C" chord, the bass is "C".

Plus globally available attributes: _c, _x, id
