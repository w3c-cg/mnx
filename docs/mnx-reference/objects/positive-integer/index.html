The positive integer object

Type: Integer

An integer of the value 1 or greater.

Parent objects

This object is used by the following parent objects:

  • measure repeat counter: "count"
  • multi-note tremolo: "marks"
  • note value quantity: "multiple"
  • single-note tremolo: "marks"
  • staff config: "lines"
  • time signature: "count"
