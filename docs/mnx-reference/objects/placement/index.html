The placement object

Type: String

Represents a symbol or object's vertical placement relative to an event, staff or other object. See also multi-staff placement, which supports multi-staff music.

A symbol's placement may also be used to determine other visual aspects of that symbol, such as the direction of bracket hooks or the direction the symbol points. Many symbols, however, have additional ways to specify shapes (such as fermata's "pointing"), which override any changes of shape implied by placement.

Allowed values:

Value Description
"above"
"auto" Consuming applications are free to use their own algorithms to determine placement.
"below"
