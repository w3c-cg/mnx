The notehead shape object

Type: String

A semantic notehead shape.

This is a higher-level concept than individual SMuFL glyphs, because a single notehead shape may be represented by different SMuFL glyphs depending on rhythm. For example, the notehead shape "oval" is typically represented as the SMuFL glyph "noteheadHalf" for half notes, "noteheadBlack" for smaller rhythmic values, etc.

Allowed values:

Value Description
"circleX" An X enclosed in a circle.
"custom" An otherwise unclassified notehead. Requires an explicit glyph on the notehead object.
"default" For a kit note, uses the head design defined by its kit component. Otherwise, the notehead shape is determined by the consuming software. Normally this is an oval shape.
"diamond" A diamond-shaped notehead.
"oval" Conventional oval notehead.
"plus" A plus-shaped notehead.
"slash" A rhythmic slash notehead.
"square" A square notehead, as used for La in shape-note notation. This does not by itself select a shape-note system.
"triangle" A triangular notehead with its tip pointing up, irrespective of stem direction.
"triangleDown" A triangular notehead with its tip pointing down, irrespective of stem direction.
"x" An X-shaped notehead.
