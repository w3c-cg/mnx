The label ref type object

Type: String

Allowed values:

Value Description
"auto" Consuming software should choose between the part's "name" and "shortName" according to its own algorithm. Typically the "name" is used on the first system and the "shortName" on subsequent systems.
"name" Use the part's "name" attribute.
"shortName" Use the part's "shortName" attribute.
