The chord suffix SMuFL run object

Type: Dictionary

A run of SMuFL glyphs within a chord suffix, rendered in the music font.

This is typically used for glyphs from the SMuFL chord-symbol range, such as csymMajorSeventh, csymDiminished, csymHalfDiminished, and csymAugmented, or for chord-symbol accidentals such as csymAccidentalFlat. For example, "7(♭9)" with a music-font flat:

{"content": [{"text": "7("}, {"type": "smufl", "glyphs": ["csymAccidentalFlat"]}, {"text": "9)"}]}

Enclosing parentheses and brackets for stacks, and the slash for diagonal stacks, should not be encoded as glyphs. They are implied by stack attributes.

Attributes

Name Type Required? Description
type The string "smufl" Yes This disambiguates SMuFL runs from text runs and stacks.
glyphs An array of smufl glyph objects Yes List of SMuFL glyphs to display, in order.
level chord suffix level No The vertical level of this run.

If omitted, the default value is "baseline".

Plus globally available attributes: _c, _x, id
