The sequence object

Type: Dictionary

The sequence object organizes a set of musical events within a measure into a strict temporal sequence.

To determine the measure position of each event within a sequence, you sequence the content, with a starting position 0 and time modification ratio 1.

The content within each sequence supplies the music for a single polyphonic voice within its containing measure, including notes, chords, rests, tuplets and grace notes.

Attributes

Name Type Required? Description
content An array of event objects, grace objects, tuplet objects, space objects, multi-note tremolo objects Yes The content of this sequence. Because the array elements are heterogeneous (event vs. grace vs. tuplet, etc.), each element has a "type". The "type" is assumed to be "event" if left unspecified, because events are by far the most common case.
directionHint direction-hint No Encodes this sequence's vertical position, relative to other sequences in the same part measure. Essentially, it answers the question "Is this an upper voice, or a lower voice?"

This is optional and is meant as a hint for consuming applications that structure their internal data differently depending on whether a voice is upper or lower. It can also be used as a hint for individual events' stem directions, if they're not explicitly encoded as event.stemDirection.

Note it's possible for multiple sequences within the same part measure to have the same directionHint value (for example, in the case of more than two sequences).

If omitted, the default value is "auto".
fullMeasure full measure rest No Specifies that this sequence is a full-measure rest, and contains optional information about that full-measure rest.

Typically, full-measure rests get special treatment by notation apps: they're centered horizontally within the bar and they might use a rest glyph that doesn't necessarily match the bar's duration.

If a sequence has fullMeasure defined, then the sequence's content must be an empty array.

Note the full measure rest object has no required attributes of its own. It's valid for fullMeasure to be set to an empty object: {}. In this case, this means the sequence is indeed a full-measure rest, with default full-measure rest attributes.
staff staff number No The default staff number of the content in this sequence. This is used in cross-staff keyboard notation. If not provided, the value is assumed to be 1 (the first staff in the part).
voice voice name No A string that identifies the voice to which this sequence belongs. All sequences in a given part having the same value of "voice" belong to the same voice. Within a given measure, no two sequences may share the same value for voice. The value of voice is an opaque identifier that does not supply information from producers to consumers.

Plus globally available attributes: _c, _x, id
