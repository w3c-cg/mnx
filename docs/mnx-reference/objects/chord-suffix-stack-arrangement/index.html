The chord suffix stack arrangement object

Type: String

How the rows of a chord suffix stack are arranged.

Allowed values:

Value Description
"diagonal" Exactly two rows. The first row is placed above and to the left of the second, separated by a diagonal slash drawn by the consuming software (for example, the SMuFL glyph csymDiagonalArrangementSlash). This is commonly used for "6/9".
"vertical" Rows are placed directly above one another, with no separator.

Parent objects

This object is used by the following parent objects:
