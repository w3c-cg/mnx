The chord suffix text run object

Type: Dictionary

A run of Unicode text within a chord suffix.

A run may contain any number of characters. A suffix needs more than one run only where the level changes or where a SMuFL glyph or a stack appears.

Attributes

Name Type Required? Description
type The string "text" No Optional. This disambiguates text runs from SMuFL runs and stacks. If a part has no type, applications should assume type=text.
text string Yes The text of this run, which can be any Unicode text. Accidentals may be encoded with Unicode characters such as ♭ (U+266D), ♮ (U+266E), and ♯ (U+266F), and quality symbols with characters such as ° (U+00B0), ø (U+00F8), Δ (U+0394), + and − (U+2212).

Consuming software renders this text in its chord-symbol text font.
level chord suffix level No The vertical level of this run.

If omitted, the default value is "baseline".

Plus globally available attributes: _c, _x, id

Parent objects

This object is used by the following parent objects:
