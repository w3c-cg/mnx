The chord suffix object

Type: Dictionary

Draft. This object is a proposal for committee review and is not yet referenced from any other object in MNX.

Represents the displayed suffix of a chord symbol: everything that follows the root, such as "m7", "maj7(add9)", or "7(♭9 ♯11)". The bass note of a slash chord is not part of the suffix.

A suffix describes appearance only. It does not change the harmonic meaning of the chord, which is encoded separately (for example, by a chord kind). Two chords with the same meaning can have different suffixes, such as "maj7" and "Δ7".

A suffix is a sequence of parts. Each part is one of:

  • a text run, which is any Unicode text;
  • a SMuFL run, which is one or more SMuFL glyphs from the music font; or
  • a stack, which arranges two or more rows of runs vertically or diagonally, optionally enclosed in parentheses or brackets.

A suffix does not specify fonts, point sizes, text effects, or offsets. Consuming software chooses these from its own chord-symbol style. Parts may instead be given a semantic level, such as superscript, and stacks are drawn smaller than the baseline text, according to the consuming software's style. Consuming software is also responsible for optical adjustments, such as raising accidentals or parentheses slightly to align them with neighboring digits.

Software that cannot draw stacks may flatten a suffix to a single line of text by concatenating its parts in order, joining the rows of each stack with "/" and keeping any enclosure as ordinary parentheses or brackets.

Examples:

"maj7(add9)" as plain text:

{"content": [{"text": "maj7(add9)"}]}

"Δ9", using the SMuFL major-seventh glyph:

{"content": [{"type": "smufl", "glyphs": ["csymMajorSeventh"]}, {"text": "9"}]}

"MA⁷", with a superscript extension:

{"content": [{"text": "MA"}, {"text": "7", "level": "superscript"}]}

"6/9", with the 6 stacked above the 9:

{"content": [{"type": "stack", "rows": [{"content": [{"text": "6"}]}, {"content": [{"text": "9"}]}]}]}

"6/9", arranged diagonally:

{"content": [{"type": "stack", "arrangement": "diagonal", "rows": [{"content": [{"text": "6"}]}, {"content": [{"text": "9"}]}]}]}

"7" followed by ♭9 stacked above ♯11, enclosed in tall parentheses:

{"content": [{"text": "7"}, {"type": "stack", "enclosure": "parentheses", "rows": [{"content": [{"text": "♭9"}]}, {"content": [{"text": "♯11"}]}]}]}

"add9" stacked above "omit3", enclosed in tall parentheses:

{"content": [{"type": "stack", "enclosure": "parentheses", "rows": [{"content": [{"text": "add9"}]}, {"content": [{"text": "omit3"}]}]}]}

Attributes

Name Type Required? Description
content An array of chord suffix text run objects, chord suffix SMuFL run objects, chord suffix stack objects Yes The parts of the suffix, rendered left to right in the order provided, starting immediately after the chord's root.

Plus globally available attributes: _c, _x, id
